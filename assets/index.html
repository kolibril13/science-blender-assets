Science Blender Assets

A remote asset library for Blender 5.2 and newer.

Library URL

https://kolibril13.github.io/science-blender-assets/

Adding it to Blender

  1. Open Edit ▸ Preferences.
  2. Under System ▸ Network, turn on Allow Online Access.
  3. Go to Asset Libraries, press + and choose Add Remote Asset Library.
  4. Paste the URL above into the URL field.

The assets now appear in the Asset Browser and Asset Shelf, and download on demand — right-click an asset and choose Download Asset. Online libraries cannot be linked, so the import method is Append or Pack.
